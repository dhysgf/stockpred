# A股多模型决策系统 · 展示站

静态展示站：多模型量化预测 + K线形态 + 量能资金 + 大模型新闻/政策研判 + 拐点模型。

## 文件说明

- `index.html` 落地页：任意 6 位代码在线生成报告入口、模型下拉（标注百炼免费额度）、Key 留出即用服务器内置
- `analysis.html` 完整逐项分析：8 个面板 + 预测图/K线图 + 浏览器端复跑研判（Key 由访客自填，直连厂商）
- `report_*.html` 本地模型实跑生成的报告（图片已 base64 内嵌，单文件可分享）
- `forecast_688836_deep.html` 宇树科技深度预测：三情景概率 + 估值反推 + 机构目标价分歧 + 事件日历
- `analysis_snapshot.json` 10 只股票的实跑结果结构化快照
- `news_snapshot.json` 对应股票的真实新闻快照（供浏览器端复跑研判）
- `img/` 预测图与 K 线形态图

## 部署

- **实时版**（能对任意股票现场训练）：本机 `python web.py` → Cloudflare 隧道。
  池外标的会自动并入训练池，因此不限沪深300。
- **静态版**（本目录）：CloudStudio / GitHub Pages 均可托管。

## Key 说明

- 后端路径（`/report`、`/analyze`）：Key 留空 → 用服务器内置 Key；访客也可自带 Key 覆盖（仅存服务端内存，按会话隔离）
- 浏览器端复跑研判（`analysis.html`）：**必须访客自己填 Key**，因为是浏览器直连厂商，服务器 Key 不会下发到浏览器

内容为算法输出，不构成投资建议。
