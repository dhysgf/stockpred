为什么在线数值可能和本地报告不一样

  • 在线页渲染的是一次真实运行的快照（价格预测、形态、量能、拐点、决策全在）， 但浏览器跑不了 sklearn + PyTorch + 300 只股票池，所以不能换股票实时重算。
  • 新闻研判可以复跑：换模型（qwen-plus / deepseek-chat / glm-4-flash）后情绪、政策影响、 置信度会浮动 —— 这是模型差异 + 采样随机，不是 bug。
  • 后端那次调用额外附带当日行情上下文（收盘价、近 5/20 日涨跌、量比、主力净额占比）， 在线复跑没有这几项，数值通常更保守。

它是怎么算的

环节做法
价格预测每个周期只做 一次 直接回归（DIRMO），预测「第 N 个交易日的收盘价」，不逐日滚动
多模型随机森林 / 梯度提升 / LSTM 等权融合，成员分歧用于估计不确定性
目标区间max(多模型分歧, 波动率外推) × 1.28，约 80% 覆盖；区间宽度即"该不该重仓"的信号
新闻与政策大模型读新闻/政策，输出情绪与政策影响两路信号，各自加权进决策
买卖点由目标区间 + MA5/MA20/ATR 推出低吸区、突破确认价、止盈区、止损位

这个系统的诚实边界

  • 短周期（1~5 日）方向准确率约 52~53%，只比抛硬币好一点点。
  • 30 日方向准确率实测 48.3%，还不如抛硬币 —— 所以 30 日刻意不给方向，只给价格区间。
  • 新闻与政策的影响无法回测（历史上没存当时的新闻文本），只能算"有信息价值"，不算"已验证有效"。
  • 用当前成分股回测历史存在幸存者偏差，策略超额要打折看。
  • 数据新鲜度按「数据日」判，不按文件时间：报告页顶部的「数据截至」是行情源最新一根日线； 若数据落后，页面顶部会黄条提示并给出「重新分析」按钮（浏览本身不会触发重训）。

关于在线版的能力边界

这个在线版是静态站点：量化模型（sklearn + PyTorch + 300 只股票池）无法在浏览器里运行， 所以报告是预先生成的。浏览器里能实时跑的只有大模型研判那一段（用你自己的 Key）。

要完整体验「输入任意股票代码 → 实时训练 → 出报告」，请在本地运行： 
pip install -r requirements.txt
python make_report.py --symbol 600519 --run     # 跑分析 + 出带图报告
python web.py                                   # 打开网页版（支持填自己的 Key）
数据来源：新浪财经（行情）、东方财富（新闻）。大模型：服务器内置 Key（访客可留空直接用，或自带 Key 覆盖）。
